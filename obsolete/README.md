# Obsolete and historical material

This directory is kept for reproducibility and provenance. It is not required
for the current package or tutorial.

- `notebooks/`: previous monolithic notebooks
- `experimental-results/`: dated experiments and superseded result tables
- `data/`: temporary or exploratory tables
- the remaining scripts and R files: legacy preprocessing and modelling code

For current use, start with the repository `README.md` and the notebook under
`notebooks/`.
